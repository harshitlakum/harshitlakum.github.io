Numerical Methods & Scientific Computing

A curated set of numerical-analysis repositories in Python and MATLAB: finite-difference schemes, ODE/PDE solvers, stability demonstrations, Krylov methods, interpolation, and core factorizations. Each entry includes concise descriptions, runnable scripts, and plots for study, teaching, and research.

VIEW
01

Numerical Schemes & Stability Analysis

Python/MATLAB scripts for high-order finite differences (order verification), a 2D Poisson finite-difference solver with Dirichlet BCs and convergence analysis, and a numerical demonstration of the Lax–Richtmyer stability theorem for linear time-stepping schemes.

Includes

  • fd_derivative_order · 4th-order derivative & accuracy plots
  • poisson2d_fd · 2D Poisson solve + error vs mesh size
  • lax_richtmyer_stability_demo · stability bound verification

02

Numerical-ODE-PDE-Solvers-2-

A compact set of ODE and high-dimensional integration demos in Python/MATLAB: explicit Euler (fixed/adaptive), RK4 for linear systems, implicit midpoint vs explicit Euler for stiffness, and Monte Carlo integration for multidimensional quadrature.

Highlights

  • Adaptive step control and stability comparisons
  • Stiffness behavior via implicit midpoint
  • Monte Carlo integration & curse of dimensionality
VIEW
03

Numerical-ODE-PDE-Solvers

Side-by-side Python/MATLAB implementations for classic ODE/PDE solvers: Explicit vs Symplectic Euler, CG for SPD Laplacians (with/without preconditioning), and restarted GMRES for unsymmetric systems (with/without ILU).

Scripts

  • euler_logistic_compare · logistic IVP vs exact
  • symplectic_euler_oscillator · energy-aware integration
  • cg_laplace_compare · PCG vs CG
  • gmres_test · restarted GMRES & ILU
VIEW
04

CG Spectrum Demo

Demonstrates how eigenvalue clustering/outliers affect CG convergence. Includes SD vs CG on 2D Laplace, relative A-norm error plots per iteration, and overlays of theoretical convergence bounds.

Structure

  • python/ and matlab/ experiments
  • figures/ with publication-ready plots

05

Numerical Methods Toolkit

From-scratch implementations for root-finding and unconstrained minimization: 1D bisection/newton/secant, Newton for systems, Armijo line search, and Newton+Armijo for n-D optimization. Python and MATLAB/Octave, modular and well-documented.

Provided Methods

  • Bisection, Newton (1D), Secant
  • Newton (systems)
  • Armijo line search & Newton-Armijo

Numerical Methods Toolkit (2)

Core approximation and quadrature routines in Python/MATLAB: polynomial least-squares fitting, natural cubic spline interpolation, trigonometric interpolation via FFT, and the composite trapezoidal rule for integration.

Algorithms

  • Least-squares polynomial fit
  • Natural cubic splines
  • FFT-based trig interpolation
  • Composite trapezoidal rule

07

Numerical Linear Algebra & Interpolation Toolkit

Implementations of essential linear-algebra routines plus interpolation: Householder-QR solver, Cholesky (SPD) factorization, LU decomposition/solver, and a natural cubic spline demo—each with runnable examples.

Files

  • householder_qr_solver, cholesky_spd, LU_decomposition
  • natural_cubic_spline_demo

08

LU-Cholesky-GaussianElimination Toolkit

Clean implementations of LU (with/without partial pivoting), Gaussian elimination, back substitution, and Cholesky with SPD checks. Separate Python/MATLAB folders, ready to run and compare.

Algorithms Included

  • Back substitution (upper-triangular)
  • LU with partial pivoting (PA=LU) and in-place LU (no pivoting)
  • Cholesky with positive-definiteness checks
